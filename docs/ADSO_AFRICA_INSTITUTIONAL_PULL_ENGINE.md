# ADSO AFRICA — Institutional Pull Engine

## Objective
Create automated, ethical inbound institutional demand across Africa without making ADSO dependent on the founder's physical presence.

## Core loop
`VERIFIED PUBLIC INFORMATION → AI CONTEXT → PUBLIC VALUE → DISCOVERY → INBOUND INTEREST → QUALIFICATION → HUMAN DIPLOMATIC FOLLOW-UP`

## Automated visibility
1. Collect only approved public/official information.
2. Verify provenance, date and country.
3. Classify relevance to mobility, vulnerable road users, apprentices, youth, education, prevention and skills.
4. Generate evidence-grounded editorial drafts.
5. Run diplomacy and safety checks.
6. Publish useful country-aware content.
7. Offer a neutral institutional dialogue path.
8. Score first-party inbound interest.
9. Generate a private briefing for the ADSO team.
10. Recommend a respectful next action.

## Pull surfaces
- Living country intelligence pages for African countries.
- Institutional use-case pages without claiming endorsement.
- Public mobility and vulnerable-user self-checks.
- Apprentice mobility safety diagnostic.
- Institutional mobility-readiness diagnostic.
- ADSO Africa Intelligence, refreshed from verified evidence.

## Inbound lifecycle
`DISCOVERY → VISIT → TOOL USE → REQUEST → QUALIFICATION → BRIEFING → DEMO → PILOT DISCUSSION → FORMAL AGREEMENT`

No stage implies a partnership until an actual agreement exists.

## AI qualification
The AI may summarize and classify an inbound request, prepare a briefing, suggest a response and recommend a human next action. It must never invent institutional facts, infer sensitive attributes, impersonate officials or claim endorsement.

## Founder-independent operation
Requests from countries where the founder is absent must be handled through multilingual briefing, remote demonstration, discovery calls, digital pilots, reporting and follow-up workflows. Physical presence is optional.

## Diplomatic guardrails
Never imply that an institution needs ADSO, that ADSO is an official partner, that public beneficiaries can be transferred, that a public program should finance ADSO, or that ADSO has endorsement without documented evidence.

Preferred language: “ADSO has developed…”, “based on public information…”, “we would welcome an exchange…”, “if relevant to your priorities…”, “a limited joint exploration could be considered.”

## Success metrics
Qualified institutional visits, country coverage, repeat visits, tool completions, inbound requests, demo requests, response time, pilot discussions and conversion by country/institution type. Optimize for qualified trust, not vanity traffic.

## Strategic moat
`COUNTRY KNOWLEDGE + TRUSTED SOURCING + AFRICA-NATIVE CONTENT + IMMERSIVE PRODUCT + INSTITUTIONAL WORKFLOWS + LEARNING EVIDENCE + INBOUND INTELLIGENCE`

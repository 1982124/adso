# ADSO — build principles

ADSO should guide the learner instead of making the learner guess.

## Current priorities
1. Real pedagogical course content and a resilient course reader.
2. A learner cockpit with an obvious next action from progression.
3. Mobile-first Android behavior and resilient loading/error states.
4. Exercises and assessments connected to competencies.
5. Media metadata linked to country, road-user type, competency, language, and regulatory version.
6. AI that personalizes learning without inventing regulatory facts.
7. Safety as the product outcome.

## Shipping rule
A feature is called shipped only when it is in `main`, deployed, and manually tested on the target device/browser.

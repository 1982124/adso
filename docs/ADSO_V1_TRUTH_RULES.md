# ADSO V1 — Truth Rules

- `implemented` means code exists.
- `reachable` means a production route resolves.
- `functional` means the user can complete the intended action and observe the persisted result.
- `production-proven` means the complete acceptance journey has been executed against production.
- `GO` means production-proven with no critical regression.

These statuses must never be conflated.

## Public-first learning

Public educational content remains accessible without an account. Account creation is required when persistence, personalized path, assessment history, library entitlement, or protected functionality provides a concrete reason.

## Country and language

Africa is represented as a 54-country selection domain. Learner languages for V1: French, English, Spanish, Arabic, Portuguese. Native languages may be added later when quality and speech support are demonstrably adequate.

## Media

Illustrations are mandatory learning assets for lessons. AI-generated media is allowed and preferred where appropriate; it must be labelled internally by provenance and never described as camera-filmed when it was AI-generated.

## Regulatory integrity

A country profile is not a legal certification. Automated information monitoring can surface candidate updates, but publication of an official-rule claim requires source/version/date governance.
